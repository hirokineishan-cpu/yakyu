野球記録（統合版・試験用）

■ GitHub
  リポジトリに v2 というフォルダを作り、この中のファイルを入れてください。
  今ある index.html / analysis.html は触りません。
      <あなたのサイト>/v2/   ← ここで開く

  今使っているアプリとは保存領域を分けてあります（STORE="-t"）。
  最初に一度だけ接続とログインが必要です。試験中に何が起きても
  今のアプリのデータには影響しません。

■ Apps Script（フィジカルを使うために必要）
  1. コード.gs を、同梱の Code.gs の中身で置き換える
  2. ファイルを1つ追加して Physical.gs の中身を貼る
  3. 関数 setupPhysical を実行する
       → 「青森山田 フィジカル計測」というスプレッドシートが作られ、
          測定項目16件が入り、設定シートにIDが書き込まれます
  4. デプロイ → デプロイを管理 → 鉛筆 → バージョン「新バージョン」→ デプロイ
       ※「新しいデプロイ」は押さないこと（URLが変わります）

■ 権限
  フィジカルは「管理」と「強化」だけが見られます。
  ユーザーシートの権限欄に「強化」と書いたアカウントを作れば、
  記録・閲覧の人にはサーバーがデータを返しません。
